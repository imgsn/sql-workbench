# SQL Workbench preview
A focused database-tool layout: stable dark navigation, paired source and target
selectors, and readable comparison tables. Schema differences are the centerpiece.
Palette: navigation #172438; canvas #f4f6fa; paper #ffffff; ink #233249;
action blue #315ed0; success teal #247d6a. Amber and red encode differences.
Type: Segoe UI for controls, Cascadia Code/Consolas for SQL and typed values.
Left-aligned content, 8px spacing rhythm, restrained rounding, no gradients.
Counts belong to results, not decorative dashboard cards. Visible demo labels;
no live-connection claims or simulated timings. Mobile gets horizontal navigation.
